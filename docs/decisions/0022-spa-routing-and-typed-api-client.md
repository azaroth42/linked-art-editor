# ADR-0022: SPA routing with React Router, typed API client with openapi-fetch

**Status:** Accepted · **Date:** 2026-11-22 · **Decided by:** Claude Opus 5.5 (Phase 1 Step 1.16, conventions §8.2: the spec and guide name neither library) · **Recorded by:** Claude

## Context
Step 1.16 asks for a router (`/`, `/edit/:id`, `/records/:id/history`, `/login`), a `src/api/client.ts` that "wraps `fetch` with credentials and typed paths" over types generated by `openapi-typescript`, and a committed `schema.d.ts`. Decision D1 fixes React 19, Vite, TanStack Query, and Tailwind, but no router and no client library. The guide generates the types from a running server (`http://localhost:8000/openapi.json`), which CI cannot check without starting one.

## Decision
- **Routing:** `react-router` (v8) data router: `createBrowserRouter(routes)` in `main.tsx`, `createMemoryRouter(routes)` in tests, one `routes` table in `src/app/routes.tsx` with the `AppShell` layout route. Later steps add routes to that table and may use its loaders and navigation blockers (e.g. unsaved-draft prompts).
- **Typed client:** `openapi-fetch`, the companion of `openapi-typescript`, created with `credentials: "include"` and the page origin; `unwrap()` turns every non-2xx response into an `ApiError` holding the backend's `{code, path, params}` body. TanStack Query hooks per resource live in `src/api/hooks/<resource>.ts`.
- **Generation:** `lae.app.openapi_document()` builds the document without serving the app or reading `LAE_*`; `scripts/export_openapi.py` prints it and `corepack pnpm api:generate` pipes it into `openapi-typescript`. The result is byte-identical to the guide's command against a running server. `corepack pnpm api:check` regenerates and diffs, and runs in the CI `frontend` job.

## Consequences
Any change to an endpoint's path, parameters, or models fails CI until `schema.d.ts` is regenerated and committed, and the compiler then flags every caller the change breaks. `schema.d.ts` is excluded from Prettier so the check compares the tool's exact output.
