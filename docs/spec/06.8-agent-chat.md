## 6. Schema-Driven UI & Ergonomics (continued)

### 6.8 Embedded Agent Chat Workbench

* **Collapsible Chat Drawer & Workspace Context Grounding:** Collapsible side panel in the React 19 workbench allowing catalogers and editors to instruct AI agents in natural language. Automatically attaches removable context chips representing the user's live working context: open record JSON-LD and draft diff, dual-pane Visual Merge Workbench pair, active `Set` or Dynamic Smart Set, selected TanStack Table grid rows, selected Force-Directed Graph nodes, or an open `qa_findings` item—plus scoped `@agent` handoffs directly from anchored discussion threads.  
* **Streaming Tool Cards, Confirmation Gates & Turn-Scoped Undo:** Streams responses over SSE with collapsible tool-call cards linking directly to edited records, draft diffs, or created `curation_proposals`. High-impact actions (merges, multi-record agent jobs) render explicit in-chat **Confirm / Cancel** action cards before execution, and every draft-editing turn offers a 1-click **"Revert Agent Turn"** button backed by scoped Yjs transactions.  
* **Curated Model Selector (Local & Cloud):** Presents admin-approved model profiles clearly badged **Local** vs. **Cloud** (local 4B–32B models, Google Gemini, Anthropic Claude, OpenAI, or institutional Vertex/Bedrock/Azure endpoints), governed by an instance-level `local_only` vs. `allow_cloud` policy toggle.
