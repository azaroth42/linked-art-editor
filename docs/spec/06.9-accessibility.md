## 6. Schema-Driven UI & Ergonomics (continued)

### 6.9 Accessibility (WCAG 2.2 Level AA)

* **Target Compliance Standard:** All public-facing surfaces (especially the Lightweight Public Reader at `/id/{uuidv7}`) and institutional authoring/admin workspaces must conform to **WCAG 2.2 Level AA**.  
* **Dragging Movements & Target Size (SC 2.5.7 & SC 2.5.8):** Every drag-and-drop interaction (Entity Workbench to form slots, Force-Directed Graph node drops, image/IIIF URL drops, and Vocabulary Manager term reordering) must provide single-pointer and full keyboard equivalents (e.g., *"Link to slot..."* action menus, `Move Up / Move Down` controls, and `@dnd-kit` keyboard drag announcements). Interactive controls in dense cataloging views (`classified_as` pill chips, remove icons, timeline markers, TanStack Table cells) must maintain at least **24×24 CSS px** target sizes (or compliant target spacing).  
* **Focus Not Obscured & Visual Canvas Parity (SC 2.4.11 & SC 2.4.13):** Sticky headers, validation drawers, the Agent Chat sidebar, and dual-pane split views must enforce `scroll-margin`, non-obscured focus, and high-contrast focus indicators. Non-text canvases always maintain accessible equivalents: MapLibre + Terra Draw pairs with raw WKT, `.geojson` upload, and sidecar gazetteer search forms; Force-Directed Graph and React Flow mini-graph pair with the semantic HTML Backlinks list, keyboard-navigable node inspector, and `prefers-reduced-motion` simulation pausing; Mermaid diagrams include SVG `<title>`/`<desc>` metadata and a keyboard-accessible structured text/table toggle; and IIIF viewers supply keyboard controls and ARIA descriptions sourced from Linked Art statements / canvas labels.  
* **Screen-Reader Discipline for CRDTs & Streaming AI:** Polite `aria-live` regions announce only intentional status events (SHACL validation summaries, publish confirmations, chat turn completion, active editor join/leave)—never remote character-by-character CRDT keystrokes or Yjs Awareness cursor jitter.  
* **CI Accessibility Enforcement:** Automated **axe-core + Playwright** accessibility checks run in CI across the Lightweight Public Reader and core editor/admin routes alongside keyboard-only cataloging smoke tests.
