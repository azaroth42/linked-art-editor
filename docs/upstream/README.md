# Upstream items for the Linked Art schema and documentation

- `linked-art-schema-mismatches.md` is generated by `scripts/report_schema_mismatches.py`: every corpus file that fails the vendored JSON Schema, with every error. Rerun it after upstream fixes.
- Items found by other means, not visible in the generated list:
  - **BCE dates:** `format: date-time` in the schema is RFC 3339 (four-digit years only), so valid Linked Art bounds such as `-0500-01-01T00:00:00Z` would fail once format checking is on. Suggest a pattern that allows signed years, or documenting the limit. (Spike S4; `docs/questions.md` Step 0.9.)
  - **Unresolvable `$ref`:** `provenance.json` refers to `core.json#/$defs/LegalRight`, which does not exist (also in the generated list).
  - **Uncommitted local json-validator edits** to `abstract.json`, `core.json`, and `linked_art.json` are vendored; commit them upstream, then update `profiles/schema/SOURCE.md` (`docs/questions.md` Step 0.4).
